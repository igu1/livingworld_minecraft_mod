# Living World

**A world that grows with you.**

> **Status: in development.** The features below are planned and not yet available for download.

A more alive world: moss and vine spread, snow accumulation and animal migration, all configurable.

## Features

### Moss & Vine Spread
Naturally growing moss and vines across the world.

### Snow Accumulation
Snow builds up over time in cold biomes.

### Animal Migration
Animals move between areas instead of staying put.

## Requirements

- **Minecraft 26.1.2**
- **NeoForge 26.1.2.108 or newer**
- **Java 25** (bundled with Minecraft 26.1)
- Planned features; not yet released.

## Installation

1. Install **NeoForge** for Minecraft 26.1.2.
2. Drop the `.jar` into your `mods/` folder.
3. Launch the game. That is it — no dependencies and no configuration required to start.

## Compatibility

- Works in single-player and on any server (client-side where noted).
- Should be compatible with most other mods. Please report conflicts in the issue tracker.
